# 02-Methodology

## Purpose

This directory defines **how claims are evaluated** within the Strataract Completion Hypothesis (SCH) project.

Methodology documents are **procedural**, not scientific. They establish the standards by which claims are documented, reconstructed, compared, reproduced, classified, and audited. They do **not** modify or replace canonical theory.

The methodology is intended to ensure that every conclusion reached by the project can be traced to an explicit derivation, evaluated under consistent rules, and reproduced independently where possible.

## What Belongs Here

Methodology documents define **evaluation procedures**, including:

* Documentation requirements
* Scope discipline
* Comparability rules
* Evidence classification
* Derivation requirements
* Reproducibility standards
* Claim classification
* Audit protocols
* Category discipline

These documents answer questions such as:

* *What constitutes a complete derivation?*
* *When are two constructions comparable?*
* *How should a claim be classified?*
* *What evidence is required before a claim is considered established?*

---

## What Does **Not** Belong Here

This directory does **not** contain:

* new theoretical claims,
* revised equations,
* physical mechanisms,
* reconstruction findings,
* empirical conclusions,
* alternative models.

Those belong elsewhere in the repository.

---

## Guiding Principle

Methodology defines **how the project reasons**, not **what the project concludes**.

Changing a methodology document changes the evaluation procedure for the entire repository and therefore requires governance-level justification.
