# Analyses

Here you will find various analyses, working hypotheses, and supportive and experimental work carried out in connection with the Strataract Completion Hypothesis. Some of this work has direct impact on the content of the papers; some is exploratory and may not appear in the main suite. These folders are provided as base reference — for transparency about how conclusions were reached, what was tried, and what the data actually showed at each stage of the work.

Not everything here confirmed the framework. Null results, reinterpreted results, and analyses that were redone from scratch when methodological problems were identified are part of the record. Each subfolder contains its own README describing what the analysis is, what it found, and what its current status is.
