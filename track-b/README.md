# Track-B: Unresolved Issues

This directory serves as the active staging ground for open technical investigations, anomalies, and active peer-review disputes.

### Purpose
* **Active Work-in-Progress:** Houses ongoing calculation audits, convention conflicts, or experimental discrepancies requiring formal review.
* **Pipeline Staging:** Items remain in this directory until a formal consensus or analytical resolution package is compiled, at which point the final record is migrated to the `resolved` directory.
